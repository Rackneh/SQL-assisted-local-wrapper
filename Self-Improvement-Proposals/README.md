# Dory IBA Self-Improvement Proposals

This directory houses autonomous self-improvement proposals generated by the Dory IBA system when identifying memory inefficiencies, execution bottlenecks, or architectural optimization opportunities during task execution.

## Directory Hierarchy

- `01-memory-architecture/`: Relational schema enhancements, chunking strategies, indexing, deduplication, and caching improvements.
- `02-execution-efficiency/`: Tool dispatch optimizations, loop control, latency reductions, and prompt token budget compaction.
- `03-codebase-cognition/`: Structural symbol extractors, mental map accuracy, incremental updates, and hash-based invalidation.
- `04-general-workflows/`: Task decomposition heuristics, error-recovery mechanisms, and contract verification checks.

## Format Specification

Each proposal is written as a structured markdown file named `YYYY-MM-DD_<descriptive-slug>.md` with the following sections:
1. **Context & Observation**: The specific task, operation, or query that triggered the observation.
2. **Inefficiency / Limitation Identified**: Detailed description of what is sub-optimal or redundant.
3. **Proposed Enhancement**: Concrete technical proposal, code change, or schema adjustment.
4. **Expected Impact**: Estimated token savings, latency improvements, or reliability gains.
